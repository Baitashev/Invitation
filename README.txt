САЙТ-ПРИГЛАШЕНИЕ НА СВИДАНИЕ
=============================

Готов для GitHub Pages.

1. КАК ИЗМЕНИТЬ ДАТУ / ВРЕМЯ / МЕСТО / ИМЕНА
------------------------------------------------
Открой файл script.js.
В самом верху есть блок:

const invite = {
  girlName: "Салима",
  yourName: "Бекназар",
  date: "16 августа 2026",
  time: "19:00",
  place: "Место-сюрприз 💌",
  ...
};

Меняй только значения в кавычках.

2. КАК ПОСТАВИТЬ ВАШИ ФОТОГРАФИИ
---------------------------------
Открой папку assets и замени файлы:
- photo1.jpg
- photo2.jpg
- photo3.jpg

Важно: новые фотографии должны иметь ТОЧНО такие же имена.
Лучше использовать горизонтальные фото, но сайт нормально работает и с вертикальными.

3. КАК ПОСТАВИТЬ СВОЮ МУЗЫКУ
-----------------------------
В папке assets замени music.mp3 на свою песню.
Название должно остаться music.mp3.

Важно: современные браузеры запрещают автоматическое воспроизведение звука без действия пользователя.
Поэтому музыка запускается при первом нажатии/касании страницы или после кнопки «Конечно».

4. КАК ПРОВЕРИТЬ НА КОМПЬЮТЕРЕ
------------------------------
Просто открой index.html в браузере.

5. КАК ЗАЛИТЬ НА GITHUB PAGES
-----------------------------
- Создай новый публичный репозиторий GitHub.
- Загрузи ВСЕ файлы из этой папки в корень репозитория.
- Settings → Pages.
- Source: Deploy from a branch.
- Branch: main, folder: /(root).
- Save.
- Через некоторое время GitHub покажет адрес сайта.

СТРУКТУРА
---------
index.html
style.css
script.js
README.txt
assets/
  photo1.jpg
  photo2.jpg
  photo3.jpg
  music.mp3

Подсказка: не переименовывай index.html — GitHub Pages ищет именно этот файл.


6. АДАПТАЦИЯ ПОД iPHONE 16 PRO MAX
-----------------------------------
Версия оптимизирована под большой экран iPhone 16 Pro Max в портретной ориентации:
- учтены safe-area вокруг Dynamic Island и Home Indicator;
- используется динамическая высота 100dvh для Safari;
- кнопки имеют удобный размер для пальца;
- кнопка «Нет» не должна убегать под системные области и панели Safari;
- приглашение компактнее размещает детали в 2 колонки;
- добавлена отдельная адаптация для горизонтальной ориентации.

Для лучшего результата открывай сайт в Safari без увеличенного масштаба страницы (100%).
